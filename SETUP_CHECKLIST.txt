STEP-BY-STEP EXECUTION:
═════════════════════════════════════════════════════════════════════════════

PHASE 1: GET YOUR API KEY (5 minutes)
─────────────────────────────────────
☐ 1. Open browser
☐ 2. Go to: https://aistudio.google.com/app/apikey
☐ 3. Click "Create API Key"
☐ 4. Select "Create API key in new project"
☐ 5. Copy the generated key
☐ 6. Could take a page like this:
      sk-proj-abcdefg1234567890xyz...
☐ 7. Don't close this yet - you'll need it in Phase 2

PHASE 2: CREATE .ENV FILE (2 minutes)
─────────────────────────────────────
☐ 1. Open Notepad or VS Code
☐ 2. Create a NEW file
☐ 3. Type exactly this:
      GEMINI_API_KEY=paste_your_key_here
      NODE_ENV=production
      PORT=3000
☐ 4. Replace "paste_your_key_here" with key from Phase 1
      Example:
      GEMINI_API_KEY=sk-proj-abcdefg1234567890xyz...
      NODE_ENV=production
      PORT=3000
☐ 5. Save the file as: .env
      Location: c:\Users\ADMIN\Desktop\portfolio\.env
☐ 6. IMPORTANT: Don't add any extra spaces or quotes around the key

PHASE 3: INSTALL DEPENDENCIES (3 minutes)
──────────────────────────────────────────
☐ 1. Press Windows key + R
☐ 2. Type: powershell
☐ 3. Press Enter
☐ 4. Type: cd c:\Users\ADMIN\Desktop\portfolio
☐ 5. Press Enter
☐ 6. Type: npm install
☐ 7. Wait for all packages to download (you'll see lots of text)
☐ 8. When done, you should see: "added X packages"

PHASE 4: START ROCKY (1 minute)
───────────────────────────────
☐ 1. In same PowerShell window, type: npm start
☐ 2. Press Enter
☐ 3. You should see:
      Rocky's backend is running on port 3000 🚀
      API endpoint: http://localhost:3000/api/chat
☐ 4. DO NOT CLOSE THIS WINDOW - keep it open
☐ 5. ✅ ROCKY IS NOW RUNNING!

TROUBLESHOOTING - IF SOMETHING GOES WRONG:
═════════════════════════════════════════════════════════════════════════════

PROBLEM: "npm: command not found" or "npm is not recognized"
SOLUTION: 
  ☐ Download Node.js from: https://nodejs.org
  ☐ Install it (default options fine)
  ☐ Restart PowerShell
  ☐ Try again: npm install

PROBLEM: "Cannot find module '@google/generative-ai'"
SOLUTION:
  ☐ Run again: npm install
  ☐ Wait for it to complete fully
  ☐ Try npm start again

PROBLEM: "Port 3000 already in use"
SOLUTION:
  ☐ Edit .env file
  ☐ Change: PORT=3001
  ☐ Restart server: npm start
  ☐ Update URL in script.js if needed

PROBLEM: Rocky doesn't respond / says "thinking too hard"
SOLUTION:
  ☐ Check .env file - API key correct?
  ☐ Check internet connection
  ☐ Look at browser console (F12) for errors
  ☐ Verify server is still running (PowerShell window open?)

PROBLEM: "ENOENT: no such file or directory"
SOLUTION:
  ☐ Make sure you're in correct folder: cd c:\Users\ADMIN\Desktop\portfolio
  ☐ Verify .env file exists: ls -Name .env
  ☐ Re-create .env if needed
